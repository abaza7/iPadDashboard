Add this remote to your Home Screen

iPhone / iPad: open this page in Safari, tap the Share button, then Add to Home Screen. Do it while you're connected, so the code is saved in the shortcut. If it ever asks for the code, enter it once.

Android: in Chrome tap the ⋮ menu, then Install app (or Add to Home screen).

Commands go through the free ntfy.sh service to the dashboard, which must be open, awake and online. “Reload app” makes iPadOS require one tap on the iPad before adhan sound works again.
